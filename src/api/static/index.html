    How the number is made

    Data
    1,500 listings generated at metro-city rates per square foot, with gaps, duplicates and outliers left in, then cleaned.
    Model
    A scikit-learn pipeline feeds XGBoost, chosen over Random Forest and Linear Regression on held-out homes.
    Range
    Conformalized quantile regression: two quantile models, widened on a calibration split until 90% of unseen prices fall inside.
    Reasons
    Each feature is reset to a typical listing's value in turn; the change in price is that feature's share.
